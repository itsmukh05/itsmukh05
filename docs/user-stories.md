# User Stories

Format: As a [type of user], I want [goal], so that [reason or benefit].

## User Story 1: Manage Tasks
As a student, I want to organize my tasks, so that I can track my progress.

**Acceptance Criteria**
- Given I have a task, when I view my task list, then the task is displayed.
- Given I complete a task, when I mark it as complete, then its status is updated.

## User Story 2: Track Requirements
As a project team member, I want requirements to have unique IDs, so that I can reference them easily.

**Acceptance Criteria**
- Each requirement has a unique ID.
- User stories can reference the related requirement ID.

## User Story 3: View Project Information
As a visitor, I want the README to explain the project structure, so that I can understand the repository.

**Acceptance Criteria**
- The README describes the purpose of the project.
- The README lists the main project folders and their purposes.
